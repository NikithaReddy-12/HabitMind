# Dayline - Voice-First Health & Wellness Journal

Dayline is a modern, calm, voice-first daily health and wellness tracker built with vector memory (Qdrant Cloud) and AI extraction (Lyzr Agent).

## Key Features

- **Voice-First Journaling**: Tap the pulsing microphone orb or use interim-to-final streaming transcription to speak naturally about your sleep, mood, hydration, energy, and activities.
- **Quick-Add Lifestyle Chips**: One-tap tags like "Slept well", "Skipped workout", "Felt anxious", "Drank 2L water" to complement your voice notes.
- **Timeline View**: Vertical chronological timeline of all daily reflections with mood emojis, metric badges, notes preview, search, and metric filtering.
- **Bento Dashboard**: Modern bento-grid with large stat cards, 7/30/90 day segmented control, smooth area charts, mood-vs-sleep correlation analysis, and a calendar consistency heatmap.
- **Dayline Ask**: Natural-language conversational reflection engine. Ask questions like *"How was my sleep this week?"* or *"When did I last feel anxious?"* with cited date chips.
- **Weekly Insights**: Actionable health patterns categorized into positive, warning, and neutral insights with week-over-week metric delta badges.
- **Settings & Omi Integration**: Goal targets for daily sleep, hydration, and movement; full Omi wearable transcript webhook integration; and one-click CSV data export.
- **Dark Mode by Default**: Deep indigo palette with soft violet-to-teal gradients, glassmorphism cards, and an accessible light/dark theme switch.

*Disclaimer: Dayline is for lifestyle tracking, not medical advice.*
